# eCommerce-product-page-Frontend-Mentor

**Created eCommerce single product demo website with features like:**

1. **Page features**
    - Responsive design.
    - Pointer cursor on hovers.
    - Colors, opacity transition on hovers of buttons, icons.

3. **Product picture features**
    - Showcasing different shots of the product with the click of a button and with next and previous buttons.
    - Showcasing product picture in bigger size.

4. **Cart features**
    - Adding product in the cart.
    - Pop up above cart on adding products.
    - Number of products in the cart.
    - Total price of the product.
    - Delete products from the cart.
